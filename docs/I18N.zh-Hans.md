# GearUI 多语言系统

[English](./I18N.md) | [简体中文](./I18N.zh-Hans.md)

一套语言运行时服务所有层。GearUI Kit 不集中托管其他库的文案：每个库自己
定义强类型 strings，共享 GearUI 提供的语言环境。应用只需一处声明语言——
`App(languageTag = ...)`——切换时所有语言包自动重组。

## 1. 架构

```text
App (languageTag, fallbackLanguageTag, stringsOverrides)
  └── I18nRoot                                                  ← gearui-kit 提供
        ├── LocalLanguageTag         (BCP47, normalized)
        └── LocalFallbackLanguageTag (BCP47, normalized)
              ├── I18nProvider   (LocalStrings)                 ← gearui-kit 自用
              ├── PrivChatUiI18nProvider (LocalPrivChatUiStrings) ← 上层库自己挂
              ├── ... 任意层
              └── content
```

每个 Provider：

- 读 `LocalLanguageTag.current` / `LocalFallbackLanguageTag.current`；
- 从自己的 builtin map 解析 base pack（`resolveLanguagePack`）；
- 应用调用方传入的 `Map<String, XxxPatch>` 字段级覆盖；
- 用 `remember(tag, fallback, overrides)` 缓存 immutable 结果；
- 通过 `staticCompositionLocalOf` 暴露给同库组件。

类型安全 + 字段级覆盖 + 单点语言切换 + 应用层零样板。

## 2. 接入步骤（上层库）

业务应用跳过本节——`App(languageTag = ...)` 就够了。

### 2.1 Strings 模型与 Patch

```kotlin
@Immutable
data class PrivChatUiStrings(
    val messageDeleted: String,
    val chatTyping: String,
)

@Immutable
data class PrivChatUiStringsPatch(
    val messageDeleted: String? = null,
    val chatTyping: String? = null,
)

val PrivChatUiStringsPatch.isEmpty: Boolean
    get() = messageDeleted == null && chatTyping == null

fun PrivChatUiStrings.merge(patch: PrivChatUiStringsPatch?): PrivChatUiStrings {
    if (patch == null || patch.isEmpty) return this
    return copy(
        messageDeleted = patch.messageDeleted ?: messageDeleted,
        chatTyping = patch.chatTyping ?: chatTyping,
    )
}
```

### 2.2 内置语言包

```kotlin
object PrivChatUiStringPacks {
    val English: PrivChatUiStrings = PrivChatUiStringsEnUs
    val ChineseSimplified: PrivChatUiStrings = PrivChatUiStringsZhHans

    val builtIn: Map<String, PrivChatUiStrings> = mapOf(
        "en-US" to English, "en" to English,
        "zh-Hans" to ChineseSimplified, "zh-CN" to ChineseSimplified,
        "zh" to ChineseSimplified,
    )
}
```

### 2.3 Provider 与访问器（核心）

```kotlin
val LocalPrivChatUiStrings = staticCompositionLocalOf { PrivChatUiStringPacks.English }

@Composable
fun PrivChatUiI18nProvider(
    overrides: Map<String, PrivChatUiStringsPatch> = emptyMap(),
    content: @Composable () -> Unit,
) {
    val tag = LocalLanguageTag.current          // 来自 App / I18nRoot
    val fallback = LocalFallbackLanguageTag.current
    val strings = remember(tag, fallback, overrides) {
        resolveLanguagePack(tag, PrivChatUiStringPacks.builtIn, fallback)
            .merge(resolvePatch(tag, fallback, overrides))
    }
    CompositionLocalProvider(LocalPrivChatUiStrings provides strings, content = content)
}

object PrivChatUiI18n {
    val strings: PrivChatUiStrings
        @Composable get() = LocalPrivChatUiStrings.current
}
```

`resolvePatch` 会归一化覆盖 key，并沿 tag 的子标签链回退
（`zh-Hans-CN → zh-Hans → zh`），最后落到 fallback tag。

### 2.4 应用层挂载

```kotlin
App(
    languageTag = lang,
    stringsOverrides = mapOf(             // 可选：覆盖 GearUI 内置文案
        "zh-Hans" to StringsPatch(common = CommonStringsPatch(confirm = "确定一下")),
    ),
) {
    PrivChatUiI18nProvider(               // 可选：覆盖库语言包
        overrides = mapOf("zh-Hans" to PrivChatUiStringsPatch(messageDeleted = "这条消息已撤回")),
    ) {
        AppContent()
    }
}
```

## 3. 语义域拆分（强制）

单个 `Strings` data class 膨胀到几十个字段后，Kotlin 生成的 `copy` /
`equals` / `hashCode` / `componentN` 会把类字节码推向 DEX 方法上限与 255
参数上限——Android 上表现为加一个 key 就运行期 `VerifyError`，且只在
Android 端复现。所以文案按语义域拆成小 data class：

```kotlin
// gearui-kit 的域：common / theming / field / dateTime / feedback / media / guide
@Immutable
data class Strings(
    val common: CommonStrings,
    val theming: ThemeStrings,
    // ...
)

data class StringsPatch(
    val common: CommonStringsPatch? = null,
    val theming: ThemeStringsPatch? = null,
    // ...
)
```

规则：

- 每个域保持在十几个字段以内；超了就再拆一个域，不要往现有域堆。
- 每个域自带 `XxxStringsPatch` / `isEmpty` / `merge`；顶层 `merge` 只做域转发。
- 新增文案 = 加到对应域 + 三份语言包全部补齐（en-US / zh-Hans / zh-Hant）。
- 门面可用委托 getter 保留扁平调用点（`strings.theme` → `theming.theme`），
  拆域不惊动既有调用方。

## 4. 带参数的文案

不要在组件里拼字符串。模板串放进语言包，占位符用 `{name}`，读取时展开：

```kotlin
// pack 里：selectedCountFormat = "已选择 {count} 项"
Text(I18n.strings.field.selectedCountFormat.formatArgs("count" to values.size))
```

## 5. 读不到 Composition 的地方

`@Composable` 函数的默认参数表达式可以读 `I18n.strings`——默认值在
composition 作用域求值。真正读不到的只有两类：

1. **命令式控制器**（如 `ActionSheet.showList(...)`）：参数设计成
   `String? = null`，在 `@Composable` 宿主里 `?: I18n.strings.common.cancel`
   兜底，仍按当前语言解析。
2. **普通类逻辑**（如 `FormFieldState.validate()`）：文案在构造期注入；直接
   构造时回落到 `StringPacks.English`（库的 fallback 语言）。绝写字面量。
   配套提供 `rememberXxx` 工厂按当前语言注入。

CI 守卫 `scripts/ci/check_i18n_default_text.sh` 拦截库源码里 i18n 包之外的
任何中文字面量，基线为 0。

## 6. 命名约定（强制）

| 角色 | 命名 |
| --- | --- |
| 数据模型 | `XxxStrings`（data class，全字段非 null） |
| 覆盖模型 | `XxxStringsPatch`（data class，全字段 nullable） |
| 内置语言常量集 | `XxxStringPacks`（object：`English` / `ChineseSimplified` / … + `builtIn: Map<String, XxxStrings>`） |
| 单语言常量 | `XxxStringsEnUs` / `XxxStringsZhHans` / `XxxStringsZhHant` |
| CompositionLocal | `LocalXxxStrings`（`staticCompositionLocalOf { XxxStringPacks.English }`） |
| Provider | `XxxI18nProvider(overrides, content)` |
| 访问器 | `object XxxI18n { val strings: XxxStrings @Composable get }` |

跨库一致命名让消费者一眼找到接入点。

## 7. 性能要求（强制）

- 要：`remember(tag, fallback, overrides)` 缓存解析结果；`merge(patch)` 在
  patch 为 null/全 null 时直接返回 receiver（零分配）；组件读
  `XxxI18n.strings` 是 O(1) CompositionLocal 查找。
- 不要：每次重组调用 `resolveLanguagePack` / `normalizeLanguageTag`；不要把
  strings 解析放进 `LaunchedEffect` 或副作用——它是纯计算。

## 8. 反模式

| ❌ 错误 | ✅ 正确 |
| --- | --- |
| 自己再做一个 `LocalLanguageTag` | 直接读 `com.gearui.i18n.LocalLanguageTag` |
| 在 `App` 下再嵌一层 `I18nRoot(...)` | `App(languageTag = ...)` 已经挂了 |
| Provider 接收 `languageTag` 参数 | Provider 只收 `overrides`，语言从 Local 读 |
| `Map<String, String>` + 字符串 key | 强类型 data class + 访问器 |
| strings 放进 `MutableState` 让组件订阅 | `staticCompositionLocalOf` + `remember` |

## 9. 兼容性

- 删除或重命名 strings 字段是 API breaking change，由
  `binary-compatibility-validator` 阻断。
- 新增 strings 字段是 source breaking（构造函数参数变多）；同一变更内必须
  补齐所有内置语言包。
- 本设计背后的运行时约束（单一 App 根、运行时所有权）属于
  [ARCHITECTURE.zh-Hans.md](./ARCHITECTURE.zh-Hans.md) 的工程规则。
