# Archive

Historical process documents: migration batch plans, one-off audits, RC
readiness snapshots, spike findings.

They are kept for traceability — they record *why* a decision was made at the
time — but they are **not** current specification. Do not treat anything here as
normative, and do not update them; they describe a moment that has passed.

Current, binding documents live one level up in `docs/`. Start at
[`../SPEC.md`](../SPEC.md).
